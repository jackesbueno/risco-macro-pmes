# risco-macro-pmes
Modelo em Python de teste de estresse macroeconômico para PMEs (TG em Gestão Financeira, Fatec). Mede a sensibilidade de Serviços de TI, Indústria e Varejo a Selic, IPCA e câmbio com dados do BCB e do IBGE (2012–2026), regressão Newey-West e Monte Carlo (VaR/CVaR), e aplica os cenários à DRE e ao balanço de empresas fictícias.
